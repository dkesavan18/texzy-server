# Texzy Server

Backend server for the Texzy application.

## Overview

This repository contains the server-side code for Texzy.

## Getting Started

```bash
# Install dependencies
npm install

# Run in development
npm run dev

# Run tests
npm test
```

## Environment

Copy `.env.example` to `.env` and fill in the required values:

```bash
cp .env.example .env
```
